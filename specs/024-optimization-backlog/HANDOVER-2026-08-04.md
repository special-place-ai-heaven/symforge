## Operational gotchas (all hit this session)

1. GitHub occasionally DROPS the CI trigger on push: branch shows zero runs.
   Fix: `gh pr close N` then `gh pr reopen N` re-fires pull_request. (PR #503.)
2. Background `gh run watch` gets killed ~10 min. Pattern: re-arm on each kill
   notification; check `gh run list --branch <b>` between arms.
3. Known wall-clock/timing flakes, ALL pass in isolation, none caused by this
   session's diffs: `test_load_perf_70_files` (<500ms budget),
   `batch_rename_health_dry_run_stays_under_h7_budget`,
   `test_index_folder_rebinds_repo_root_for_local_impact_analysis` (cwd-guard).
   Worth a dedicated de-flaking item if they keep costing reruns.
4. Empty-tree git commits with `Signature::now` mint IDENTICAL SHAs within the
   same second — use fixed-epoch signatures in divergence test fixtures.
5. rmcp-macros 3.1.0 `#[prompt_handler]` REPLACES a manually defined
   list_prompts/get_prompt (unlike `#[tool_handler]`, which defers). symforge
   hand-writes both prompt methods; do not re-add the macro.
6. `std::fs::canonicalize` on Windows yields `\\?\` UNC paths that corrupt
   `file:///` URIs — use `dunce::canonicalize`.
7. Timing: CI rust job ~27 min; local full serial suite ~15-20 min; release build
   ~12 min; cold worktree `cargo check` ~5-6 min.
