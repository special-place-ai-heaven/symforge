## Completed design work

The frozen design covers:

- one bounded pre-run scout shared by cold index, watcher, reconciliation, and
  snapshot verification;
- catalog-only accounting for huge binaries, model weights, datasets, generated
  trees, sensitive paths, unsupported encodings, and Git LFS pointers;
- code, knowledge, overlapping config/schema, and catalog-only routing;
- exact byte/line provenance without line-ending normalization;
- Markdown plus MDX, reStructuredText, AsciiDoc, Org, extensionless docs, safe
  structured configs, and safe unknown UTF-8 text;
- deterministic phrase/heading/term/path retrieval with explicit no-evidence and
  degraded-evidence states;
- source-local worktree/local-ref identity and immutable per-source publication;
- protected-root guards for home, operating-system, drive/filesystem roots, aliases,
  junctions, and symlinks, with explicit exact-root override only;
- user-local or memory-only derived state when `<source>/.symforge` is unwritable;
- idempotent `/.symforge/` insertion only when a repository-root `.gitignore`
  already exists and only during explicit project-aware initialization/binding;
- one repository mental-model bridge based only on exact links/paths/code-spanned
  symbols/declared selectors, never embeddings or bare similarity;
- lifecycle, authority domain, checked-code evidence, retrieval voice, temporal
  provenance, review, remediation, and guarded curation;
- code-as-evidence precedence only for checked current-implementation claims;
  intent, governance, decisions, security policy, and north-star material retain
  their own labeled voice;
- watcher, reconciliation, temporal, bridge, authority, and snapshot updates fenced
  to one captured immutable publication generation;
- worktrees and local refs without cross-source evidence leakage;
- secret-positive content excluded from index, outputs, CCR, analytics, diagnostics,
  hashes, summaries, and review artifacts.

## Non-negotiable implementation invariants

- Code is the evidence authority for current implemented behavior, not for intent.
- Knowledge index and code-intelligence index are separate query scopes sharing one
  scout/catalog and one atomic publication boundary.
- No embeddings/vector database in v1 without a measured failing corpus.
- No duplicate stored prose corpus or generated LLM summaries.
- Exact source/file/line/span/content identity accompanies every returned excerpt.
- No full reads/hashes/decompression for rejected huge files.
- No stale, mixed-generation, cross-source, or cross-project evidence.
- No source-local state write requirement for protected/read-only roots.
- No automatic indexing of home, OS, filesystem, drive, or broad container roots.
- No secret-positive bytes or derivatives in durable or returned state.
- Discovery/search/review does not bump code frecency.
- Curation is explicit, guarded, durable, idempotent, crash-recoverable, and never
  silently deletes.
- No visible Windows terminal windows from any SymForge child-process path.
