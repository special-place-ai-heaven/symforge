Preventive V1 lifecycle refreeze. It is evidence planning, not execution
evidence. Every referenced test is either an exact planned executable or an
explicitly inherited executable, and every row remains
`planned_not_executed`/`false` until a later implementation slice produces the
named CI artifact. Prose outside the sentinel block is non-normative.
